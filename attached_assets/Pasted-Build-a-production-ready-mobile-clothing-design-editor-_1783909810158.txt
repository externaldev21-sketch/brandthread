Build a production-ready mobile clothing design editor called “Brandthread Studio.”

IMPORTANT:
Do not copy Procreate’s exact interface, icons, branding, brush names, preset assets, source code, or screen layouts. Create an original Brandthread interface with comparable professional drawing and garment-design capabilities.

PURPOSE:
This editor opens when the user taps “Brand Studio” or “Create Design” inside the Brandthread mobile app. It should let clothing-brand owners draw artwork, create graphics, edit imported images, add typography, build garment mockups, and export production-ready files without leaving Brandthread.

TARGET PLATFORMS:
- Primary: iPhone and Android phones
- Secondary: iPad and Android tablets
- Responsive desktop/web fallback
- Touch-first
- Stylus support where available
- Apple Pencil support on iPad
- Samsung S Pen support where available

RECOMMENDED STACK:
- React Native with Expo and TypeScript for the application
- React Native Skia for the high-performance canvas and brush rendering
- React Native Gesture Handler for gestures
- Reanimated for fluid animations
- Zustand for editor state
- MMKV or SQLite for local persistence
- FileSystem for project storage
- Native image libraries for decoding and exporting
- Optional Metal-backed rendering on iOS
- Optional Vulkan/OpenGL-backed rendering on Android
- Supabase or Firebase for cloud backup and collaboration
- Do not build the drawing engine using basic HTML canvas if targeting a native mobile app
