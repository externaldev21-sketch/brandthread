# Brandthread Starter

A complete Expo Router starter for the Brandthread mobile app.

## Included

- Buyer and Seller account types
- Role-based onboarding
- Buyer Thread feed
- Buyer profile, stories, friend requests, messaging shell
- Seller dashboard
- Design Studio AI shell
- Products, manufacturers, inventory, orders, analytics, store builder
- Light and dark themes
- Supabase client setup
- Marketplace-ready data model SQL

## Run

1. Install Node.js 20+
2. Copy `.env.example` to `.env`
3. Add your Supabase keys
4. Run:

```bash
npm install
npx expo start
```

## Important

This is a production-grade starter architecture, not a finished billion-dollar marketplace. Real payments, AI image generation, shipping labels, payouts, returns, disputes, and manufacturer transactions require backend services and secret keys.
