First-run coach work is presentation-only. Invisible measurement wiring is approved only on the exact existing targets. Preserve all tip copy, eligibility, ordering, seen/skip persistence, target actions, screen layout and navigation.

**Why:** The owner explicitly prohibited unrelated changes, then narrowly approved refs/onLayout/measureInWindow or target registration in existing screen elements.

**How to apply:** Do not invent a control for screen-level copy or attach a spotlight to a merely related action. Do not add target touch observers or action handlers to screen files. The owner explicitly approved an overlay-only native fallback: tapping the cutout completes/advances the tip without activating the underlying control when safe forwarding is impossible. Web taps may continue to pass through and complete the tip.
