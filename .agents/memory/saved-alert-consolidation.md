---
name: Saved alert consolidation
description: Preserve existing preferences while consolidating overlapping saved-product price-alert features.
---

Use one saved-product price-alert preference and one delivery pipeline across collection and product-page controls. New saves require opt-in, but preserve previously stored preferences.

**Why:** The owner requires overlapping features to be consolidated without discarding existing work. The older alert feature defaulted on, while the newer product-page control requires opt-in; resetting existing rows would silently overwrite preferences, and keeping two delivery engines would risk duplicate alerts.

**How to apply:** Adapt new controls to the established preference and delivery rules, change only the default for newly saved products, and retain the existing reference-price, deduplication, visibility, block, and push-preference checks.
