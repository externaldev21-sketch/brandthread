---
name: Reference-app adaptation
description: How to translate external app screenshots and archives into Brandthread improvements.
---

When a reference app or screen archive is supplied, review it for small reusable interaction components as well as major end-to-end flows. Useful details include pending states, inline feedback, compact selectors, badges, drawers, confirmation cues, status treatments, and sticky actions.

**Why:** The user explicitly clarified that the value of a reference archive includes many small components, even though not every referenced feature belongs in Brandthread. Focusing only on headline flows misses a large part of the requested adaptation.

**How to apply:** Compare each useful interaction against existing Brandthread behavior, add only real data-backed gaps, preserve current layouts, and express borrowed patterns through Brandthread’s monochrome design system rather than copying the source app’s identity.
